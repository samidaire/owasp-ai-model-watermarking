# Data files

`poseidon_constants.json` holds the Poseidon round constants `C` and MDS matrices `M` for state widths
t = 2…17 over the BN254 scalar field. They are generated by the Poseidon authors' reference script
(`generate_parameters_grain.sage`, Grassi et al., <https://eprint.iacr.org/2019/458>) and are the
values used by circomlib/circomlibjs (file `circomlibjs/src/poseidon_constants.json`, v0.1.7), so the
Python hash in `sigil.poseidon` matches the circuits bit for bit. They are mathematical constants
fixed by the Poseidon specification; see `../../../../circuits/LICENSE` for the licence of the
circom ecosystem files the circuits use.
